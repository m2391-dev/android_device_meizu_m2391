# LineageOS 23 (m2391) prebuilt-kernel packaging mode update

Date: 2026-02-19  
Scope: `device/meizu/m2391`  
Target: switch from full prebuilt boot chain to hybrid mode:
- keep prebuilt kernel binary (`TARGET_PREBUILT_KERNEL`)
- generate `boot` / `init_boot` / `vendor_boot` during build
- keep `dtbo` / `system_dlkm` / `vendor_dlkm` as prebuilt images

## 1. Background

Previous config used:

- `TARGET_NO_KERNEL := true`
- `BOARD_PREBUILT_BOOTIMAGE`
- `BOARD_PREBUILT_INIT_BOOT_IMAGE`
- `BOARD_PREBUILT_VENDOR_BOOTIMAGE`
- `BOARD_PREBUILT_DTBOIMAGE`
- `BOARD_PREBUILT_SYSTEM_DLKMIMAGE`
- `BOARD_PREBUILT_VENDOR_DLKMIMAGE`

This made boot-chain behavior fully prebuilt-driven.

## 2. New mode

Updated `device/meizu/m2391/BoardConfig.mk`:

- set `TARGET_NO_KERNEL := false`
- keep `TARGET_PREBUILT_KERNEL := $(KERNEL_PATH)/Image`
- remove:
  - `BOARD_PREBUILT_BOOTIMAGE`
  - `BOARD_PREBUILT_INIT_BOOT_IMAGE`
  - `BOARD_PREBUILT_VENDOR_BOOTIMAGE`
- keep:
  - `BOARD_PREBUILT_DTBOIMAGE`
  - `BOARD_PREBUILT_SYSTEM_DLKMIMAGE`
  - `BOARD_PREBUILT_VENDOR_DLKMIMAGE`

## 3. Effect

- `boot.img` is generated by build rules using prebuilt kernel input.
- `init_boot.img` is generated by build rules.
- `vendor_boot.img` is generated by build rules.
- `dtbo.img`, `system_dlkm.img`, `vendor_dlkm.img` remain copied from prebuilts.

## 4. Validation checklist

1. `source build/envsetup.sh`
2. `lunch lineage_m2391-bp4a-userdebug`
3. `mka bootimage init_bootimage vendorbootimage bacon`
4. confirm output files:
   - `out/target/product/m2391/boot.img`
   - `out/target/product/m2391/init_boot.img`
   - `out/target/product/m2391/vendor_boot.img`
   - `out/target/product/m2391/dtbo.img` (prebuilt path still active)
   - `out/target/product/m2391/system_dlkm.img` (prebuilt)
   - `out/target/product/m2391/vendor_dlkm.img` (prebuilt)

## 5. Follow-up fix (same day)

After enabling `TARGET_NO_KERNEL := false`, `kati` failed in:

- `vendor/lineage/build/tasks/kernel.mk:122: error: Argument missing.`

Root cause:

- `TARGET_KERNEL_VERSION` was unset, but kernel task logic calls:
  - `is-version-greater-or-equal($(TARGET_KERNEL_VERSION),5.15)`
  - `is-version-lower-or-equal($(TARGET_KERNEL_VERSION),6.1)`
- empty version string triggers math helper argument validation failure.

Fix:

- set `TARGET_KERNEL_VERSION := 5.15` in `device/meizu/m2391/BoardConfig.mk`.
